# NovaSoft - Sistema de Gestión de Pedidos

Proyecto de ejemplo para practicar la gestión de versiones con Git.

Estado del proyecto: listo para entrega
Equipo: NovaSoft (5 desarrolladores)

## Archivos
- app.py: punto de entrada del sistema
- pedidos.py: lógica de pedidos
- clientes.py: lógica de clientes
- requirements.txt: dependencias

## Uso
python app.py
